Como rodar o jogo:

1- Baixe o arquivo e o descompacte;

2- Caso esteja fazendo uso do eclipse:
	2-1. Import > Gradle > Existing Gradle Project;
	2-2. Selecione o local em que o arquivo foi descompactado e o processo foi concluído;
	2-3. Observação: Caso esteja fazendo uso do eclipse, é importante acrescentar, caso necessário, "../" em todas as chamadas de assets ao longo do programa. Ficará algo similar a isto: Antes: "assets/imagem1.png" Depois: "../assets/imagem1.png".

3- Caso esteja fazendo uso do vsCode:
	3-1. Importe a pasta do projeto;
	3-2. Observação: Caso esteja fazendo uso do vsCode, é importante retirar, caso necessário, "../" em todas as chamadas de assets ao longo do programa. Ficará algo similar a isto: Antes: "../assets/imagem1.png" Depois: "assets/imagem1.png".
